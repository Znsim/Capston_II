## 용도

- 키오스크 카메라 앞에서 한 손으로 표현하는 정적 한국어 지문자 분류

## 한계와 금지 용도

- dim, near, far 조건의 최종 평가와 학습 미참여자 평가는 아직 완료되지 않았습니다.
- MediaPipe가 손을 검출하지 못하면 모델 자체는 실행되지 않습니다.
- 학습 분포와 다른 카메라, 조명, 피부·손 크기, 가림, 극단적 거리에서 성능이 저하될 수 있습니다.
- 연속 동작 단어 수어, 양손 동시 동작, 일반 수어 번역 모델이 아닙니다.
- 안전·의료·법률 상황에서 사람의 확인 없이 유일한 의사소통 수단으로 사용하면 안 됩니다.
