# 5단계 역무원 화면 테스트 가이드

## 적용된 동작

- 대기 질문을 자모 로그가 아닌 완성 문장 단위로 표시
- 역명, 키오스크 위치, 장치 ID, 요청 시간 표시
- 답변 성공 시 완료 항목을 대기 목록에서 제거
- 답변 실패 시 질문 선택, 답변 입력값, 대기 목록 유지
- 프론트 버튼 잠금과 DB 조건 갱신으로 빈 답변·중복 답변 방지
- 음성 입력 미지원, 권한 거부, 마이크 없음, 무음, 네트워크 오류 안내
- 겹치지 않는 순차 폴링 적용
  - 화면 활성 상태: 2초
  - 탭 비활성 또는 오류 발생: 5초
- 불필요한 채팅 메시지 배열과 비활성 채팅방 상태 제거
- 관리자 로그인 후 발급되는 HttpOnly 세션 쿠키로 API 인증

현재는 장애 대응이 쉬운 HTTP 폴링을 유지한다. 실시간성이 더 필요해질 때 SSE 또는 WebSocket으로 교체한다.

## 여러 키오스크 분리 테스트

1. 서로 다른 장치 ID를 사용하는 키오스크 두 대에서 각각 다른 문장을 전송한다.
2. 관리자 화면에서 각 항목의 역명, 위치, 장치 ID와 문장이 올바른지 확인한다.
3. 첫 번째 질문을 선택해 답변한다.
4. 첫 번째 질문만 목록에서 사라지는지 확인한다.
5. 두 번째 질문은 그대로 `WAITING` 상태인지 확인한다.
6. 각 키오스크 사용자 화면에 자기 질문의 답변만 표시되는지 확인한다.

## 실패 복구 테스트

1. 질문을 선택하고 답변을 입력한다.
2. 백엔드 서버를 잠시 중지한 뒤 답변 전송을 누른다.
3. 오류 메시지가 표시되는지 확인한다.
4. 선택한 질문과 입력한 답변이 그대로 유지되는지 확인한다.
5. 서버를 다시 실행하고 같은 답변을 재전송한다.

## 중복·빈 답변 테스트

1. 공백만 입력했을 때 답변 전송 버튼이 활성화되지 않는지 확인한다.
2. 유효한 답변의 전송 버튼을 빠르게 여러 번 눌러도 한 번만 처리되는지 확인한다.
3. 이미 완료된 `conversation_id`에 API로 다시 답변하면 `400 reply_already_completed`가 반환되는지 확인한다.

## 음성 입력 테스트

1. 음성 입력 버튼을 눌러 답변에 변환 결과가 들어가는지 확인한다.
2. 마이크 권한을 거부하고 안내 메시지가 표시되는지 확인한다.
3. 음성 인식을 지원하지 않는 브라우저에서 버튼이 비활성화되고 미지원 안내가 표시되는지 확인한다.

## 완료 기준

- [ ] 대기 질문이 완성 문장 단위로 표시됨
- [ ] 역명·위치·장치 ID·요청 시간이 정확함
- [ ] 답변 성공 항목만 목록에서 제거됨
- [ ] 답변 실패 시 UI와 입력 내용이 유지됨
- [ ] 빈 답변과 중복 답변이 차단됨
- [ ] 음성 입력 상태와 오류가 표시됨
- [ ] 여러 키오스크 질문과 답변이 서로 섞이지 않음
