# 4단계 키오스크 화면 테스트 가이드

## 환경설정

`.env`에 키오스크 장치 ID를 지정한 뒤 프론트 개발 서버를 다시 시작한다.

```dotenv
REACT_APP_KIOSK_DEVICE_ID=SEOUL_01
```

React 환경변수는 실행 시 읽으므로 값을 바꾼 뒤에는 `npm.cmd start`를 다시 실행해야 한다.

## 적용된 동작

- 완성 문장 전체를 `POST /api/conversations`로 한 번 전송
- 반환된 `conversation_id`로 답변 조회
- 한 요청씩 순차 폴링하여 중복 요청 방지
- 답변 완료, 취소, 404 오류 또는 2분 시간 초과 시 폴링 종료
- 전송 중 및 답변 대기 중 추가 전송 방지
- 질문·답변 API, AI 추론, 카메라, 음성 출력 오류 표시
- 웹캠 권한 거부, 미연결, 다른 앱 사용 중 상황 안내
- 지우기, 공백, 초기화, 전송, 재전송 버튼 제공
- 마지막 전송 문장 보관 및 명시적인 재전송 지원

## 수동 테스트

1. 문장을 만든 뒤 전송하고 관리자 화면에 완성 문장 전체가 그대로 표시되는지 확인한다.
2. 전송 버튼을 빠르게 여러 번 눌러도 대화가 한 건만 생성되는지 확인한다.
3. 관리자 답변 후 폴링이 끝나고 사용자 화면에 답변이 표시되는지 확인한다.
4. 브라우저 음성이 답변을 읽는지 확인한다.
5. 서버를 중지한 상태에서 API 오류 안내가 보이는지 확인한다.
6. 브라우저 카메라 권한을 차단한 뒤 권한 허용 안내가 보이는지 확인한다.
7. 지우기 버튼이 마지막 자모를 지우는지 확인한다.
8. 공백 버튼이 단어 사이에 한 칸만 추가하는지 확인한다.
9. 초기화 버튼이 작성 중인 문장만 비우는지 확인한다.
10. 답변 시간 초과 후 재전송 버튼이 마지막 문장을 다시 전송하는지 확인한다.

## 완료 기준

- [ ] 사용자가 만든 전체 문장이 역무원 화면에 그대로 표시됨
- [ ] 한 번의 전송으로 대화 한 건만 생성됨
- [ ] 답변 완료 후 폴링 종료
- [ ] 2분 시간 초과 후 폴링 종료 및 재전송 가능
- [ ] API·카메라·권한·음성 오류가 화면에 표시됨
- [ ] 모든 편집 버튼이 의도대로 동작함
