# 8단계 테스트 실행 가이드

이 문서는 자동화된 회귀 테스트와 실제 웹캠 사용자 테스트를 같은 기준으로 반복하기 위한 가이드다.

## 자동 테스트

프로젝트 루트에서 전체 테스트를 실행한다.

```powershell
npm.cmd run test:all
```

개별 실행이 필요하면 다음 명령을 사용한다.

```powershell
npm.cmd run test:react
venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
```

자동 테스트의 검증 범위는 다음과 같다.

- 한글 조합기: 복합 모음, 쌍자음, 단·복합 받침 이동, 삭제, 공백, 초기화
- AI 모델 계약: 63차원 입력, 잘못된 길이와 NaN 거부, 운영 모델 32개 클래스와 `label_encoder` 매핑
- API 흐름: 추론, 두 키오스크의 질문 생성, 관리자 인증, 대기 목록, 답변, 정확한 `conversation_id` 폴링, 중복 답변 방지
- React: 사용자·관리자 경로, 역무원 질문 표시, 빈 답변 방지, 전송 실패 복구, 중복 답변 방지
- 폴링·전송: 느린 요청 중 중복 호출 방지, 완료 시 정지, 1시간 가상 장시간 실행과 시간 초과, 연속 전송 잠금

## 다중 키오스크 수동 통합 테스트

1. 백엔드와 프론트를 실행한다.
2. 서로 다른 `device_id` 두 개를 등록하고 브라우저 창 또는 프로필 두 개에서 각각 질문을 보낸다.
3. 관리자 화면에서 역명·위치·문장·시간이 서로 섞이지 않는지 확인한다.
4. 첫 번째 질문에만 답하고 첫 번째 키오스크에만 표시되는지 확인한다.
5. 두 번째 질문이 계속 `WAITING`인지 확인한 뒤 답변한다.
6. 두 키오스크의 질문·답변이 각각 정확히 한 건인지 DB에서 확인한다.

## 중복 전송과 장시간 폴링 수동 테스트

- 전송 버튼을 빠르게 여러 번 눌러도 질문이 한 건만 생성되는지 확인한다.
- 답변 대기 중에는 전송·재전송 버튼이 비활성화되는지 확인한다.
- 브라우저 개발자 도구의 네트워크 속도를 낮춰도 폴링 요청이 겹치지 않는지 확인한다.
- 답변 완료 후 추가 폴링이 발생하지 않는지 확인한다.
- 답변 없이 2분이 지나면 시간 초과 안내가 표시되고 폴링이 끝나는지 확인한다.

## 실제 웹캠 사용자 테스트

자동 테스트는 실제 카메라·조명·사람의 손동작을 재현하지 못하므로 아래 항목은 사람이 수행한다.

1. Chrome에서 카메라 권한 허용과 거부를 각각 확인한다.
2. normal, dim, near, far 조건에서 지정된 좌우 손으로 자모를 입력한다.
3. 손이 화면에서 사라지면 문자가 추가되지 않는지 확인한다.
4. 복합 모음·쌍자음·받침이 포함된 문장과 공백·삭제·초기화를 사용한다.
5. 완성 문장을 전송하고 관리자 화면에 문장 전체가 그대로 표시되는지 확인한다.
6. 답변이 해당 키오스크에만 표시되고 음성으로 출력되는지 확인한다.
7. 음성 출력을 차단했을 때도 답변 텍스트가 유지되고 오류 안내가 표시되는지 확인한다.

결과는 `docs/webcam_user_test_result_template.csv`를 복사해 기록한다. 실패 항목에는 재현 절차와 화면에 표시된 요청 ID를 함께 남긴다.

## 완료 판정

- `npm.cmd run test:all`이 모두 통과해야 한다.
- 다중 키오스크와 2분 시간 초과 수동 테스트가 통과해야 한다.
- 실제 웹캠 테스트는 최소 한 명이 전체 흐름을 완료해야 한다.
- 실패가 발견되면 수정 후 자동 테스트와 해당 수동 시나리오를 다시 수행한다.
